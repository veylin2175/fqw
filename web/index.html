Верифицировать документ
Зарегистрируйте проверяемые учетные данные в сети и создайте NFT для субъекта. Хэш VC однозначно идентифицирует учетные данные.
Запрос верификации
Шестнадцатеричный 32-байтовый хэш поддающихся проверке учетных данных или любая строка для автоматического хэширования.
Ethereum-адрес владельца учетных данных. NFT будет отчеканен на этот адрес.
Проверить статус верификации
Проверьте статус ранее выданного подтверждения в цепочке по его идентификатору токена.
Проверка
ID токена NFT, полученный во время проверки.
Отозвать верификацию
Отмените on-chain проверку навсегда. Это действие является необратимым, и учетные данные будут помечены как отозванные.
ЗАПРОС НА ОТЗЫВ ЛИЦЕНЗИИ
ID токена NFT для проверки, которую нужно отозвать.
Добавить доверенного эмитента
Зарегистрируйте адрес Ethereum в качестве доверенного эмитента учетных данных в смарт-контракте IssuerRegistry.
Админ-панель: ТРЕБУЕТСЯ КЛЮЧ API
Отправить как X-API-Key заголовок.
Адрес Ethereum для регистрации в качестве доверенного эмитента.
